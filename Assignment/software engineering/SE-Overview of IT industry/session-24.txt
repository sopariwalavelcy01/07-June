Q-1 : Create a class called Song in your preferred OOP language with private properties title and artist. Add public getter and setter methods to access and modify these properties, then create an object and update its title.
ANS :  
#include <iostream>
#include <string>
using namespace std;

class Song {
private:
    string title;
    string artist;

public:
    void setSong(string t, string a) {
        title = t;
        artist = a;
    }

    void display() {
        cout << "Title: " << title << endl;
        cout << "Artist: " << artist << endl;
    }
};

int main() {
    Song song;

    song.setSong("Perfect", "Ed Sheeran");

    cout << "Before updating:" << endl;
    song.display();

    song.setSong("Shape of You", "Ed Sheeran");

    cout << "\nAfter updating title:" << endl;
    song.display();

    return 0;
}

OUTPUT :
Before updating:
Title: Perfect
Artist: Ed Sheeran

After updating title:
Title: Shape of You
Artist: Ed Sheeran

Q-3 : Imagine a Flipkart-like app: create an abstract class Product with an abstract method upload(). Then, create two subclasses, Electronics and Clothing, that each implement the upload() method to print a different upload message.
ANS :
#include <iostream>
using namespace std;

class Product {
public:
    virtual void upload() = 0;
};

class Electronics : public Product {
public:
    void upload() override {
        cout << "Uploading Electronics product to Flipkart." << endl;
    }
};

class Clothing : public Product {
public:
    void upload() override {
        cout << "Uploading Clothing product to Flipkart." << endl;
    }
};

int main() {
    Electronics electronics;
    Clothing clothing;

    electronics.upload();
    clothing.upload();

    return 0;
}

OUTPUT :
Uploading Electronics product to Flipkart.
Uploading Clothing product to Flipkart.


Q-4 : Refactor the following code so that the user’s phone number in the UserProfile class is private and can only be set or retrieved using public methods.<br><br><em><strong>Hint:</strong> Add private access modifier to the phone number and create setPhoneNumber() and getPhoneNumber() methods.</em>

#include <iostream>
#include <string>
using namespace std;

class UserProfile {
private:
    string phoneNumber;

    void setPhoneNumber(string number) {

Q-5 : Explain in your own words the difference between encapsulation and abstraction, using examples from any social media app you use daily (like Instagram or WhatsApp).
ANS :
Title: Difference Between Encapsulation and Abstraction

Encapsulation and abstraction are two important concepts of Object-Oriented Programming (OOP), but they have different purposes.

1. Encapsulation:
   Encapsulation means wrapping data and the methods that work on that data into a single unit, such as a class. It also protects the data from direct access by making it private.

Example: In WhatsApp, a user's phone number or personal information can be kept private. It cannot be directly changed by anyone. It can only be accessed or modified through controlled methods.

2. Abstraction:
   Abstraction means hiding the internal implementation details and showing only the necessary features to the user.

Example: In Instagram, when we upload a photo, we simply select the photo and tap the "Post" button. We do not need to know how Instagram processes, compresses, stores, and displays the photo internally.

Difference:

* Encapsulation focuses on protecting and controlling data.
* Abstraction focuses on hiding unnecessary implementation details.
* Encapsulation is achieved using access modifiers like private and public.
* Abstraction is achieved by showing only essential features and hiding the internal working.

In simple words, encapsulation is about "protecting the data", while abstraction is about "hiding the complexity".
